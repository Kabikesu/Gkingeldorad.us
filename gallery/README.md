# Gallery Folder

Add your gallery images to this folder. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, and `.gif`.

The homepage automatically reads the files in this folder from GitHub and builds the slideshow, dots, thumbnails, counter, autoplay, and navigation. You do not need to edit `index.html` or `script.js` when adding images.

For best results, use landscape images with a consistent aspect ratio and descriptive filenames, for example:
- FireKirin.jpg
- Orionstar.jpg
- NewGame.webp
